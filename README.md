# 📚 StudyMate AI

StudyMate AI is an AI-powered study planning web application designed to help students organize their learning and prepare for exams.

## 📖 About the Project

Students often find it difficult to decide what to study, how much time to spend on each topic, and how to prepare for upcoming exams.

StudyMate AI helps solve this problem by using AI to generate structured and personalized study plans.

The application provides two main planning features:

- 📚 Study Planner
- 📝 Exam Planner

## ✨ Features

### 📚 Study Planner

- Enter a subject to study
- Add one or multiple specific topics
- Set available study hours per week
- Select a learning goal
- Generate an AI-powered study plan
- Get a structured weekly study schedule
- Get practice and exam preparation suggestions

### 📝 Exam Planner

- Add multiple subjects
- Set a separate exam date for each subject
- Add optional topics for each subject
- Prioritize subjects based on exam dates
- Generate an AI-powered exam preparation plan
- Get revision and practice recommendations

### 🎨 User Interface

- Clean and responsive design
- Desktop and mobile-friendly layout
- Bootstrap-based interface
- Easy-to-use forms
- Clear AI-generated results

### 🤖 AI Integration

- Gemini API integration
- Retry handling for temporary API failures
- Backup AI model support
- Friendly error handling
